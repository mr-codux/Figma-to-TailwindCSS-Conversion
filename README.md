# Figma to Tailwind CSS Conversion

A responsive UX designer portfolio landing page converted from a Figma design into semantic HTML and Tailwind CSS. The project includes a complete portfolio layout with a hero section, navigation, services, portfolio work, blog content, and responsive mobile behavior.

## Preview

Open `template.html` in a browser through a local server after generating the Tailwind output stylesheet.

## Built With

- HTML5
- Tailwind CSS 4
- Tailwind CSS CLI
- JavaScript for the mobile navigation menu
- Google Fonts: Inter and Montserrat

## Project Structure

```text
.
├── assets/
│   ├── CSS/
│   │   ├── input.css       # Tailwind source entry file
│   │   └── output.css      # Generated stylesheet
│   └── images/              # Portfolio and interface assets
├── package.json
├── style.css
├── template.html            # Main page
└── README.md
```

## Requirements

- Node.js 18 or newer
- npm
- A local development server, such as the VS Code Live Server extension

## Installation

Clone the repository and install its dependencies:

```bash
git clone https://github.com/mr-codux/Figma-to-TailwindCSS-Conversion.git
cd Figma-to-TailwindCSS-Conversion
npm install
```

### Install Tailwind CSS Manually

For a fresh HTML project, install Tailwind CSS and the CLI with npm:

```bash
npm install tailwindcss @tailwindcss/cli
```

Create an input file such as `assets/CSS/input.css`:

```css
@import "tailwindcss";
```

Generate the output stylesheet:

```bash
npx @tailwindcss/cli \
	-i ./assets/CSS/input.css \
	-o ./assets/CSS/output.css \
	--watch
```

The repository already includes the Tailwind dependencies and this command as the `dev` npm script.

## Run Locally

Start the Tailwind watcher:

```bash
npm run dev
```

Then serve the project root with a local server and open `template.html`. With VS Code Live Server, right-click `template.html` and select **Open with Live Server**.

The watcher rebuilds `assets/CSS/output.css` whenever the source CSS or HTML changes.

## Customization

- Edit the page structure and Tailwind utility classes in `template.html`.
- Add or update Tailwind source styles in `assets/CSS/input.css`.
- Replace portfolio images in `assets/images/` while keeping the referenced filenames, or update the image paths in `template.html`.
- Update the page title, content, and navigation links to match your portfolio.

## Notes

- `assets/CSS/output.css` is generated by the Tailwind CLI.
- `node_modules/` is intentionally excluded from Git. Run `npm install` after cloning to restore dependencies.
- Use a local server instead of opening the HTML file directly so asset paths and browser behavior remain consistent.
